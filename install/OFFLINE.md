# 🔌 Установка без интернета

Для контура, где машина не видит ни интернета, ни нашего реестра образов. Всё, что нужно,
лежит в этом архиве - скачивать по ходу установки ничего не придётся.

---

## 🐳 Вариант с Docker

В архиве: образ, `docker-compose.yml`, `.env.example` и инструкция.

```bash
# 1. загрузить образ из файла
docker load -i karexo-image.tar.gz
```

```bash
# 2. настроить
cp .env.example .env
openssl rand -hex 32      # вписать результат в KAREXO_TOKEN_KEY
```

Откройте `.env` и заполните `KAREXO_BASE_URL` и `KAREXO_TOKEN_KEY`. Затем:

```bash
# 3. запустить
docker compose up -d
```

⚠️ В `.env` **закрепите версию**: `KAREXO_TAG=` тот же тег, что показал `docker load`. Иначе
compose попробует сходить в реестр за образом, которого в контуре нет.

---

## 🐧 Вариант без Docker

Возьмите архив под свою систему (`linux_amd64` или `linux_arm64`), распакуйте и запустите:

```bash
sudo ./install.sh
```

Подробности - в `README.md` внутри того же архива.

---

## 🔄 Обновление в контуре

**Docker:** принесите новый архив, `docker load -i karexo-image.tar.gz`, смените `KAREXO_TAG`
в `.env`, затем `docker compose up -d`.

**Без Docker:** принесите новый архив, распакуйте, `sudo ./install.sh`. Скрипт подменит бинарь
и перезапустит службу; данные и настройки не тронет.

Проверить версию принесённого файла, ничего не устанавливая:

```bash
./karexo-server -version
```

---

## 🔐 Что важно для закрытого контура

Одна строка в настройках переводит инстанс в режим, где наружу не ходит ни сервер, ни браузер:

```
KAREXO_EDITION=enterprise
```

Она включает сразу три вещи: запрет исходящих запросов, регистрацию по приглашению и строгий
CSP. Проверить, в каком режиме инстанс поднялся **на самом деле**, - ручкой без входа:

```bash
curl -s http://localhost:8080/api/policy
```

Ответ покажет `"allowOutbound": false`.

Полный перечень того, куда продукт может обращаться и чем каждое обращение гасится, - в
документе для службы безопасности (`docs/security-review.md`, реестр - `docs/egress.md`).

⚠️ **Что в закрытом контуре работать не будет и почему:**

| Не работает | Причина |
|---|---|
| Предпросмотр ссылок-закладок | Это запрос к чужому сайту; ручка отвечает `403 policy.outbound_disabled` |
| Вставки YouTube, Vimeo, Figma | Рамка тянет чужой домен; блок показывает ссылку вместо неё |
| Вход через GitHub, выгрузка в репозиторий | Обращение к `github.com`. Работает с GitHub Enterprise Server: задайте `KAREXO_GITHUB_AUTH_HOST` и `KAREXO_GITHUB_API_HOST` на свой домен |
| Уведомления в Telegram | Облачный сервис. Вебхук и Mattermost внутри вашей сети - работают |
| AI-функции с облачной моделью | Браузер обращается к провайдеру напрямую. Работает с моделью в вашей сети (Ollama, LM Studio, корпоративный шлюз) - укажите её адрес в настройках AI |
| Письма | Работают: SMTP-шлюз ваш, он внутри контура |
