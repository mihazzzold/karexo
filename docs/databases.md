# 🗂️ Базы данных

База данных - это страница, где записи хранятся строками с одинаковым набором свойств.
Задачи, контакты, реестр документов, план проекта - всё это базы.

Каждая **запись** - полноценная страница: у неё есть свойства и есть содержимое, которое можно
открыть и наполнить блоками.

## ➕ Как создать

- Боковая панель: `+` рядом с заголовком дерева или правый клик по блокноту → **«Новая база
  данных»**.
- Прямо в тексте: `/` → **Доска**, **Календарь**, **Список**, **Галерея** или **Граф** -
  создастся новая база и сразу встроится сюда нужным видом.
- `/` → **Вид базы данных** - встроить в страницу уже существующую базу.

## 👁️ Виды

У базы может быть несколько сохранённых видов. Каждый - со своим типом, своими фильтрами,
сортировками и настройками. Вкладки видов и кнопка `+` («Новый вид») - над таблицей.

| Вид | Для чего |
|---|---|
| **Таблица** | Основной вид: колонки, группировка, итоги в футере, изменение ширины колонок |
| **Доска** | Канбан по выбранному свойству-списку или статусу; карточки перетаскиваются между колонками |
| **Список** | Компактный перечень записей |
| **Галерея** | Карточки - удобно, когда у записей есть картинки |
| **Календарь** | Записи по дате; месяц листается, запись перетаскивается на другой день |
| **Таймлайн** | Полосы по датам вдоль шкалы дней |
| **Диаграммы** | Виджеты: столбики и кольцо по свойству, число-метрика (всего записей / средний прогресс) |
| **Граф** | Связи между записями |
| **Форма** | Поля новой записи и кнопка «Создать» - удобно для быстрого ввода |

Клик по **уже активной** вкладке открывает меню вида: **«Переименовать»**, **«Дублировать
вид»**, **«Удалить вид»**. Тип вида задаётся при создании и потом не меняется - чтобы «Доска»,
внезапно ставшая «Таймлайном», никого не путала. Последний оставшийся вид удалить нельзя.

## 🏷️ Типы свойств

| Тип | Что хранит |
|---|---|
| **Текст** | Произвольная строка |
| **Список** | Один вариант из настраиваемого набора, с цветом |
| **Статус** | То же, но именно для рабочего состояния записи |
| **Теги** | Несколько меток сразу |
| **Дата** | Дата (срок, дедлайн, день события) |
| **Число** | Число |
| **Человек** | Пользователь пространства |
| **Группа** | Команда/группа |
| **Прогресс** | Число с полоской выполнения |
| **Ссылка** | URL |
| **Email** | Адрес почты, кликабельный |
| **Телефон** | Номер, кликабельный |
| **Флажок** | Да / нет |
| **Файлы** | Вложения записи |
| **Формула** | Вычисляемое значение (см. ниже) |
| **Связь** | Ссылки на записи другой базы |
| **Обратная связь** | Кто из другой базы ссылается на эту запись |
| **Итог** | Свёртка значений по связанным записям |
| **Создано** | Дата создания записи (заполняется само) |
| **Кто создал** | Автор записи (само) |
| **Изменено** | Дата последней правки (само) |
| **Кто изменил** | Автор последней правки (само) |

Новая база заводится с готовым набором: Статус, Приоритет, Исполнитель, Команда, Теги, Срок,
Прогресс. Свойства можно переименовывать, удалять и добавлять свои.

## 🔎 Фильтры

Кнопка **«Фильтр»** над таблицей. Правило - это «свойство + условие + значение»; правил может
быть несколько, они объединяются через **И** или **ИЛИ**.

Набор условий зависит от типа свойства - karexo сам показывает только осмысленные:

| Тип свойства | Доступные условия |
|---|---|
| Список, статус, человек, группа | `=`, `≠`, пусто, не пусто |
| Текст | содержит, `=`, пусто, не пусто |
| Теги, связь, обратная связь | содержит, не содержит, пусто, не пусто |
| Дата, «Создано», «Изменено» | `=`, `≤`, `≥`, пусто, не пусто |
| «Кто создал», «Кто изменил» | содержит, `=`, пусто, не пусто |
| Число, прогресс, итог | `=`, `≠`, `≥`, `≤` |
| Флажок | `=` |
| Файлы | пусто, не пусто |

Фильтры действуют во всех видах: спрятанное фильтром не появится и на доске, и в календаре.

## ↕️ Сортировка

Кнопка **«Сортировка»**: свойство и направление (по возрастанию / убыванию). Правил можно
задать несколько - они применяются по порядку.

## 🧩 Группировка

Кнопка **«Группировка»** в таблице: строки собираются по свойству-списку, статусу, человеку
или группе. Отдельным тумблером пустые группы прячутся.

## Σ Итоги в футере таблицы

Под каждой колонкой - ячейка «Итог». Клик выбирает расчёт:

| Расчёт | Что считает |
|---|---|
| **Кол-во** | Сколько строк |
| **Заполнено** / **Пусто** | Сколько строк со значением и без |
| **Уникальных** | Сколько разных значений |
| **Сумма**, **Среднее**, **Мин**, **Макс** | Только для чисел и прогресса |

## 🧮 Формулы

Свойство типа **Формула** вычисляется по другим свойствам записи. Ссылка на свойство пишется
в фигурных скобках.

```
{Цена} * {Количество}
({Сделано} / {Всего}) * 100
```

Поддерживаются `+ - * /`, скобки и унарный минус. Пустое свойство считается нулём, деление на
ноль даёт прочерк.

Сверх арифметики есть функции агрегации по **связанным** записям:

| Функция | Что делает |
|---|---|
| `count({Связь})` | Сколько записей связано |
| `sum({Связь}.{Свойство})` | Сумма значений у связанных записей |
| `avg({Связь}.{Свойство})` | Среднее (пустой набор - прочерк) |
| `min(…)` / `max(…)` | Минимум и максимум |

Аргументы можно смешивать: `sum({Задачи}.{Часы}, {Задачи2}.{Часы}, 10)`.

## 🔗 Связи, обратные связи и итоги

**Связь** соединяет запись с записями другой базы: в настройках свойства выбирается целевая
база, дальше в ячейке подбираются нужные записи.

Когда вы настраиваете связь, в целевой базе **автоматически появляется свойство «Обратная
связь»** - оно показывает, кто на эту запись ссылается. Заведённую вручную обратную связь
karexo не трогает.

**Итог** сворачивает данные по связанным записям в одно число:

| Свёртка | Что считает |
|---|---|
| Кол-во связей | Сколько записей связано |
| Заполнено / Пусто | Сколько связанных записей со значением и без |
| Сумма / Среднее / Мин / Макс | Арифметика по выбранному свойству целевой базы |

## 🎨 Условный цвет строк

Настройки базы → **«Условный цвет»**. Правило красит строку, если свойство удовлетворяет
условию:

- для списка, статуса, человека - «равно» выбранному значению;
- для числа и прогресса - `≥` или `≤`;
- для даты - «просрочено», «сегодня», «на неделе».

Правила проверяются сверху вниз, побеждает первое сработавшее.

## ⚡ Шаблоны записей и автоматизации

- **Шаблон записи** - готовый набор значений свойств. Отметьте в таблице **одну** строку -
  внизу появится панель действий с кнопкой **«Сохранить как шаблон»**. После этого у кнопки
  добавления записи вырастает стрелка: «Пустая запись» или один из шаблонов.
- **Автоматизация** - правило «когда свойство становится таким-то → установить другое
  свойство». Настраивается в настройках базы, срабатывает один раз после вашей правки
  (правила не запускают друг друга по цепочке).

## 🖱️ Массовые действия

Отметьте строки таблицы галочками - внизу появится панель: сменить статус всем выбранным
сразу, удалить их или снять выбор. Если отмечена ровно одна строка, там же появляется
**«Сохранить как шаблон»**.

## ⚙️ Настройки базы

Иконка шестерёнки над видом:

| Настройка | Что делает |
|---|---|
| **Название** и **Описание** | Подпись базы |
| **Кнопка добавления · «существительное»** | Слово для кнопки: «задача» → «Новая задача» |
| **Заблокировать базу** | Запрет изменения структуры и данных |
| **Синхронизация** | Пауза синка для этой базы на текущем устройстве: правки копятся локально и уедут при включении |
| **Показывать заголовок** | Название и иконка над представлением |
| **Открывать записи по умолчанию** | Сбоку / По центру / Страницей |
| **Плотность** | Комфортно / Компактно |
| **Макет свойств записи** | Строки / Столбцом |
| **Условный цвет**, **Автоматизации** | См. выше |

Ширина колонок таблицы меняется перетаскиванием границы и запоминается в виде.
А по какому свойству раскладывается канбан, выбирается не здесь, а в самой доске - селектором
**«Доска по»** над колонками.

## 📤 Экспорт базы

Меню базы → **«Экспорт в CSV»**: выгружаются **все строки базы** (не только видимые под
фильтром) с человеческими значениями - метки вариантов, имена людей, даты, а не внутренние
идентификаторы. Файл открывается в Excel без плясок с кодировкой.

Остальные форматы - в разделе [📦 Импорт и экспорт](import-export.md).
