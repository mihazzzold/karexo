# ✍️ Редактор

Страница в karexo - это последовательность **блоков**. Абзац, заголовок, пункт списка,
картинка, таблица, встроенная база - всё это блоки. Их можно менять типом, перетаскивать,
вкладывать друг в друга и копировать целиком.

## ⌨️ Меню «/» - вставить что угодно

Наберите `/` в любом месте текста - откроется меню вставки с поиском. Стрелки `↑` `↓`
выбирают пункт, `Enter` вставляет, `Esc` закрывает. Внутри блока кода `/` остаётся обычным
символом - меню там не открывается.

Фильтр понимает и русские, и латинские слова: `/таб`, `/table`, `/код`, `/code`.

### 📝 Базовые

| Блок | Что делает | Сокращение |
| --- | --- | --- |
| Текст | Обычный абзац | - |
| Заголовок 1 / 2 / 3 | Три уровня заголовков; попадают в оглавление | `# `, `## `, `### ` |
| Маркированный список | Список с точками | `- ` |
| Нумерованный список | Список с номерами | `1. ` |
| Чек-лист | Пункты с галочками | `[] ` / `[x] ` |
| Тоггл-список | Сворачиваемый блок с вложенным содержимым | - |
| Сворачиваемый заголовок 1 / 2 / 3 | Заголовок, который сворачивает свой раздел | - |
| Цитата | Выделенная цитата | `> ` |
| Выноска | Заметка в рамке | - |
| Разделитель | Горизонтальная линия | `---` |
| Код | Блок кода с выбором языка | ` ``` ` |

Сокращения работают только в **обычном абзаце**: маркер с пробелом (`# `, `- `, `> `…)
набирается в начале строки и исчезает, как только блок сменил тип. Сокращения без пробела -
` ``` `, `$$`, `---` - срабатывают, когда абзац состоит ровно из них.

### 🖼️ Медиа

| Блок | Что делает |
| --- | --- |
| Изображение | Картинка из файла или по ссылке; клик открывает во весь экран |
| Видео / Аудио / Файл / PDF | Вложение: воспроизведение и скачивание прямо на странице |
| Закладка | Карточка внешней ссылки |
| Вставка | Встраивание внешней страницы через iframe (например видео) |

**Картинку** можно просто перетащить в страницу или вставить из буфера - блок создастся сам.
Остальные файлы прикладываются через блок «Файл». Ограничение на один файл - **25 МБ**.

У PDF и видео карточка вложения разворачивается во встроенный просмотрщик (кнопка
«Просмотр»), аудио получает компактный плеер, а «Заменить» подменяет файл, не трогая блок.

**Закладка получается сама**: вставьте в пустой абзац один только адрес `https://…` - абзац
превратится в карточку ссылки.

### 🗂️ База данных

| Пункт | Что делает |
| --- | --- |
| Таблица | Простая таблица прямо в тексте (не база данных) |
| Вид базы данных | Встроить существующую базу видом на этой странице |
| Доска / Календарь / Список / Галерея / Граф | Создать новую базу и сразу встроить её нужным видом |

Подробнее - [🗂️ Базы данных](databases.md).

### 🔗 Ссылки

| Пункт | Что делает |
| --- | --- |
| Ссылка на заметку | То же, что набрать `[[` |
| Упоминание | То же, что набрать `@` |
| Оглавление | Открывает вкладку «Оглавление» в правой панели |

### 🧪 Продвинутое

| Блок | Что делает |
| --- | --- |
| Рисунок | Схема или набросок во встроенном редакторе (Excalidraw) |
| Формула | Формула LaTeX, рисуется KaTeX; сокращение `$$` |
| Диаграмма | Диаграмма Mermaid: блок-схемы, последовательности и т.п. |
| Кнопка-заготовка | Кнопка, которая вставляет заранее описанный набор блоков |

Некоторые пункты меню помечены значком **«скоро»** - они видны, но пока не вставляются.

## 🔡 Форматирование текста

Выделите текст мышью - над ним появится панель форматирования.

| Кнопка | Что делает | Клавиши |
| --- | --- | --- |
| «Превратить в…» | Смена типа блока (текст, заголовок, список, цитата, код…) | - |
| **B** | Жирный | `⌘B` / `Ctrl+B` |
| *i* | Курсив | `⌘I` / `Ctrl+I` |
| U | Подчёркнутый | `⌘U` / `Ctrl+U` |
| S | Зачёркнутый | - |
| `</>` | Моноширинный код внутри строки | `⌘E` / `Ctrl+E` |
| 🔗 | Ссылка (пустое поле - убрать ссылку) | `⌘K` / `Ctrl+K` |
| Цвет | Цвет текста и фона фрагмента, включая свой оттенок | - |
| 💬 | Комментарий к выделенному | - |

Выделение маркером - `⌘⇧H` / `Ctrl+Shift+H`.

Формула внутри строки: наберите `$e=mc^2$` - фрагмент сам станет формулой.

## 🔗 Ссылки на страницы `[[…]]`

Есть два способа поставить ссылку на страницу:

1. **Набрать `[[`** - откроется список страниц; выберите нужную стрелками или мышью.
2. **Скопировать ссылку и вставить.** Правый клик по странице в боковой панели →
   «Копировать ссылку», затем `⌘V` / `Ctrl+V` в тексте: вместо длинного адреса появится
   аккуратная ссылка с заголовком страницы. Так же работает «Копировать ссылку на блок» из
   меню блока `⠿` - переход прокрутит страницу прямо к нему.

Ссылки работают в обе стороны: на странице-адресате во вкладке **«Бэклинки»** правой панели
видно, кто на неё ссылается, а вкладка **«Граф»** рисует связи страниц целиком.

## 👤 Упоминания `@`

Наберите `@` в начале слова - меню предложит:

- **быстрые даты** - «Сегодня», «Завтра», «Через неделю» (вставятся текстом);
- **людей** вашего пространства - вставится связь с человеком, а сам он получит уведомление.

## 🧱 Работа с блоками

### Мышью

- **`⠿` слева от строки** - меню блока: «Превратить в», «Дублировать», «Копировать»,
  «Копировать ссылку на блок», «Комментировать», «Цвет», «Удалить».
- **Перетаскивание за `⠿`** - переставить блок; если бросить сбоку от другого блока, получится
  колонка.
- **Рамка выделения** - протяните мышью по свободному месту страницы: все блоки, попавшие в
  полосу, выделятся (у краёв экрана страница подкручивается сама).

### С клавиатуры

| Действие | Клавиши |
| --- | --- |
| Новый блок | `Enter` |
| Перенос строки внутри блока | `Shift+Enter` (в блоке кода - обычный `Enter`) |
| Слить с предыдущим блоком / сбросить тип | `Backspace` в начале строки |
| Перейти в соседний блок | `↑` / `↓` на краю текста |
| Дублировать блок | `⌘D` / `Ctrl+D` |
| Переместить блок вверх / вниз | `Alt+Shift+↑` / `Alt+Shift+↓` |
| Переместить блок в колонку слева / справа | `Alt+Shift+←` / `Alt+Shift+→` |
| Выделить текст блока, затем все блоки | `⌘A` / `Ctrl+A` (нажать дважды) |
| Копировать / вырезать / вставить выделенные блоки | `⌘C` `⌘X` `⌘V` / `Ctrl+C` `Ctrl+X` `Ctrl+V` |
| Удалить выделенные блоки | `Backspace` или `Delete` |
| Снять выделение / закрыть меню | `Esc` |
| Отменить / вернуть | `⌘Z` / `⌘⇧Z` (или `⌘Y`); `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` |

### Вставка из буфера

Markdown вставляется разобранным: заголовки, маркированные и нумерованные списки, чек-листы,
цитаты, разделители, блоки кода (` ```js `), формулы (`$$…$$`) и диаграммы (` ```mermaid `)
становятся настоящими блоками. Картинка `![](…)` превращается в блок-изображение, а внутренняя
ссылка на страницу karexo - в аккуратную ссылку на эту страницу.

Инлайн-разметка тоже понимается: `**жирный**`, `*курсив*`, `` `код` ``, `[текст](ссылка)`.

> ℹ️ Таблицы markdown (строки с `|`) блоком-таблицей **не становятся** - они вставятся
> обычными абзацами. Таблицу удобнее создать через `/` → «Таблица» или вставить из браузера
> либо офисного редактора: при вставке HTML ячейки разбираются по абзацам.

## 🎛️ Настройка страницы

Меню `⋯` в верхней панели:

| Пункт | Что делает |
| --- | --- |
| **Шрифт** | Три плитки вверху меню: «По умолч.», «Засечки», «Моно» |
| **Мелкий текст** | Уменьшает кегль страницы |
| **Ширина** | Узкая / Средняя / Полная |
| **Заблокировать** | Защита от случайных правок |
| **Дублировать** | Копия страницы |
| **Переместить в…** | В другой блокнот |
| **Объединить с…** | Блоки уходят в конец выбранной страницы, исходная - в корзину |
| **Экспорт** | Markdown, HTML, PDF (через диалог печати) |
| **История версий** | Просмотр и откат к прошлому состоянию |
| **Удалить** | В корзину (обратимо) |
| **Бэклинки** | Показывать вкладку «Бэклинки» в правой панели |
| **Управлять свойствами…** | Свойства страницы: статус, приоритет, дата, исполнитель, теги и свои поля |

### Свойства страницы

Кроме готовых полей можно завести собственные. Типы: **Текст**, **Число**, **Дата**,
**Флажок**, **Выбор**, **Ссылка**, **Пользователь**, **Группа**. У свойства есть **область
действия**:

| Область | Где работает |
| --- | --- |
| **Эта страница** | Только здесь |
| **Дочерние** | Эта страница и все вложенные |
| **Глобальное** | Любая страница пространства |

Если перенести страницу к родителю, где такого свойства нет, значение скроется, но не
потеряется - вернёте страницу обратно, и оно снова покажется.

## 🧭 Правая панель

| Вкладка | Что показывает |
| --- | --- |
| **Оглавление** | Заголовки страницы, клик прокручивает к нужному |
| **Бэклинки** | Кто ссылается на эту страницу |
| **Граф** | Карта связей между страницами |
| **Комментарии** | Треды обсуждений, счётчик нерешённых |
| **Свойства** | Статус, приоритет, дата, исполнитель, теги |
| **Инфо** | Когда страница создана и изменена и кем, счётчики слов, знаков, блоков и бэклинков |

> ℹ️ Вкладка **«Бэклинки»** по умолчанию скрыта - включается в меню страницы `⋯`.
> Вкладка **«Граф»** включается в **Настройки → Плагины → «Граф-вид»**.

## 🔍 Поиск

`⌘K` / `Ctrl+K` открывает командную палитру. Пустой запрос показывает список документов,
введённый текст ищет по заголовкам и содержимому всех страниц; в результатах видно, из какого
блока фрагмент, а `Enter` открывает страницу с прокруткой к нему. Тумблер в палитре включает
поиск и по корзине.

`⌘⇧F` / `Ctrl+Shift+F` открывает тот же поиск напрямую.
