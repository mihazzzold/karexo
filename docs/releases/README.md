## 🔢 Что означает номер

Номер состоит из трёх чисел: **МАЖОР.МИНОР.ПАТЧ**, например `0.1.0`.

| Часть номера | Когда меняется | Что это значит для вас |
|---|---|---|
| **МАЖОР** (первое число) | Крупные изменения, несовместимые с прошлым | Перед обновлением стоит прочитать заметки к выпуску |
| **МИНОР** (второе) | Появились новые возможности | Обновление безопасное, добавилось новое |
| **ПАТЧ** (третье) | Только исправления | Обновляйтесь смело |

> ⚠️ Пока первое число - **0**, продукт молодой. Это значит, что заметные изменения
> могут приезжать и в минорных выпусках. Смотрите список изменений перед обновлением.

В именах тегов и образов перед номером стоит буква `v`: `v0.1.0`.

## 🔍 Какая версия у меня

Два способа:

1. **В приложении** - «Настройки» → «О программе». Там же кнопка проверки соединения с сервером.
2. **Запросом к серверу** - адрес `/healthz` отвечает JSON вида:

   ```json
   { "status": "ok", "version": "v0.1.0" }
   ```

Если вместо номера версии вы видите `dev`, значит сервер собран из исходников вручную,
без указания версии, - это нормально для самостоятельной сборки.

## 🐳 Где брать образы

karexo распространяется готовым **Docker-образом**. На каждый выпуск автоматически:

- собирается образ и публикуется в **GitHub Container Registry (`ghcr.io`)**
  под двумя тегами - номером версии (`v0.1.0`) и `latest`;
- создаётся страница выпуска на GitHub со списком изменений.

| Тег образа | Кому подойдёт |
|---|---|
| `v0.1.0` и другие точные номера | 🔒 Промышленная установка: версия зафиксирована, обновление происходит только когда вы сами смените тег |
| `latest` | 🧪 Быстро посмотреть свежее; на важных данных лучше не использовать |

Точный адрес образа и команда запуска - в [инструкции по установке](../установка.md).

## ⬆️ Как обновиться

Коротко:

1. Посмотрите в [CHANGELOG.md](../../CHANGELOG.md), что изменилось между вашей версией и новой.
2. Смените тег образа на нужный и перезапустите контейнер.
3. Данные (база и вложения) хранятся в отдельном томе и при смене образа никуда не деваются.

> 💾 Резервная копия перед обновлением - хорошая привычка. В самом приложении есть
> «Экспорт всего пространства» в ZIP: это ваш быстрый запасной вариант на уровне содержимого.

## 📖 Как читать список изменений

CHANGELOG составлен по соглашению [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/):
версии идут сверху вниз от новых к старым, внутри каждой - три раздела.

| Раздел | Что внутри |
|---|---|
| **Добавлено** | Новые возможности |
| **Изменено** | То, что работало и раньше, но теперь работает иначе |
| **Исправлено** | Починенные ошибки |

Отдельно есть блок **🚧 Пока в разработке** - честный перечень того, чего ещё нет,
чтобы вы не тратили время на поиски.
