# 🪟 Установка karexo на Windows

Один файл: приложение внутри него, папки со статикой рядом нет. Работает службой - запускается
вместе с системой и переживает выход из учётной записи.

Нужны Windows 10/11 или Windows Server 2019+ и права администратора.

---

## ⚠️ Сначала про предупреждение Windows

**При первом запуске Windows скажет, что не может проверить издателя.** Так и есть: файл не
подписан сертификатом издателя, и мы говорим об этом прямо, а не прячем за инструкцией мелким
шрифтом.

**Почему.** Сертификат подписи кода стоит около $200 в год. Пока karexo в бете и покупателей у
него нет, эти деньги честнее не тратить - подпись не сделала бы продукт безопаснее, только
убрала бы окно. Появятся продажи - появится и подпись.

**Что это значит для вас.** Подпись подтверждает, кто выпустил файл, и что его не подменили по
дороге. Без неё это надо проверить самому - способ ниже.

### Как убедиться, что файл наш

Скачивайте **только** со страницы выпусков: `github.com/mihazzzold/karexo/releases`. Рядом с
архивом опубликована контрольная сумма. Сверьте:

```powershell
Get-FileHash .\karexo-server.exe -Algorithm SHA256
```

Совпала с опубликованной - файл ровно тот, что мы собрали. Не совпала - **не запускайте** и
напишите нам.

### Как пройти окно SmartScreen

1. В окне «Система Windows защитила ваш компьютер» нажмите **«Подробнее»**.
2. Появится кнопка **«Выполнить в любом случае»**.

Если файл скачан браузером, Windows могла его «заблокировать» - тогда снимите метку:

```powershell
Unblock-File .\karexo-server.exe
Unblock-File .\install.ps1
```

## 📦 Установка

Распакуйте архив, откройте **PowerShell от имени администратора** в этой папке:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\install.ps1
```

Первая строка разрешает запуск скрипта **только в этом окне** - навсегда политику менять не
нужно.

Скрипт сделает всё сам: создаст каталоги, **сгенерирует ключ шифрования**, заведёт службу и
запустит её. Ничего вводить не требуется.

Дальше два шага:

1. впишите свой адрес в `C:\ProgramData\karexo\karexo.env` (строка `KAREXO_BASE_URL`);
2. `Restart-Service karexo`.

Откройте `http://localhost:8080`. **Первый зарегистрированный аккаунт становится владельцем
инстанса** - регистрируйтесь сразу.

Другой порт: `.\install.ps1 -Port 9000`.

## 🗂️ Что и куда легло

| Путь | Что это |
|---|---|
| `C:\Program Files\karexo\karexo-server.exe` | Сам сервер вместе с приложением - один файл |
| `C:\ProgramData\karexo\` | **Все данные**: база и вложения. Это и есть то, что нужно копировать |
| `C:\ProgramData\karexo\karexo.env` | Настройки. Доступ только у системы и администраторов: внутри пароль от почты |
| Служба `karexo` | Автозапуск, перезапуск после сбоя (через 5, 10 и 30 секунд) |

Настройки служба читает из своего ключа реестра - в Windows нет аналога `EnvironmentFile`.
Скрипт переносит их туда из текстового файла сам, поэтому правите вы понятный файл, а не
`regedit`. **После правки нужен `Restart-Service karexo`** - без него служба работает со старыми
значениями.

## 🔄 Обновление

Скачайте новый архив, распакуйте и запустите тот же скрипт от администратора:

```powershell
.\install.ps1
```

Служба остановится, файл заменится, служба запустится. **Настройки и данные не трогаются**,
ключ шифрования не перезаписывается. Если служба не поднялась, скрипт покажет журнал и не станет
уверять, что всё хорошо.

Проверить версию, не запуская сервер:

```powershell
& 'C:\Program Files\karexo\karexo-server.exe' -version
```

## 🔐 HTTPS

Проще всего дать karexo самому получить сертификат - в `karexo.env`:

```
KAREXO_TLS=auto
KAREXO_TLS_DOMAIN=notes.example.org
KAREXO_ADDR=:80
```

Нужны публичный домен, указывающий на эту машину, и **открытые снаружи порты 80 и 443** (по 80
идёт проверка владения). В отличие от Linux, права на порты ниже 1024 в Windows службе не нужны.

Для своего сертификата - `KAREXO_TLS=file` плюс `KAREXO_TLS_CERT` и `KAREXO_TLS_KEY`.

⚠️ `auto` не работает в закрытом контуре: получение сертификата - обращение к Let's Encrypt. При
`KAREXO_ALLOW_OUTBOUND=false` служба откажется стартовать и скажет об этом прямо.

## 💾 Резервные копии

**Вручную** - кнопка «Резервная копия» в разделе «Сервер».

**По расписанию** - три строки в `karexo.env`:

```
KAREXO_BACKUP_DIR=C:\ProgramData\karexo\backups
KAREXO_BACKUP_EVERY=24h
KAREXO_BACKUP_KEEP=7
```

**Целиком каталог** - остановите службу на время копирования:

```powershell
Stop-Service karexo
Compress-Archive -Path C:\ProgramData\karexo\* -DestinationPath karexo-backup.zip
Start-Service karexo
```

## 🧹 Снятие

```powershell
.\install.ps1 -Uninstall
```

Убирает службу и программу. **Данные и настройки остаются** - удалите сами, если больше не нужны:

```powershell
Remove-Item -Recurse C:\ProgramData\karexo
```

## ❓ Если что-то не так

| Симптом | Что смотреть |
|---|---|
| Служба не запускается | `Get-EventLog -LogName Application -Source karexo -Newest 20` |
| Скрипт не запускается | `Set-ExecutionPolicy -Scope Process Bypass -Force` в том же окне |
| Правка настроек ни на что не влияет | Нужен `Restart-Service karexo`: служба читает окружение при старте |
| Не приходят письма | Не заданы `KAREXO_SMTP_*`. Проверка настроек - в разделе «Сервер» |
| Приглашение ведёт не туда | `KAREXO_BASE_URL` не совпадает с реальным адресом |
| Порт занят | Смените `KAREXO_ADDR` в настройках либо ставьте с `-Port` |
