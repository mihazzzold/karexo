# 📚 Справка karexo

karexo - база знаний, которая работает на вашем сервере. Страницы собираются из блоков,
списки задач и проекты живут в базах данных, а всё вместе синхронизируется между устройствами
через ваш собственный инстанс karexo.

Эта справка написана для того, кто работает в karexo каждый день, а не настраивает его.
Разделы можно читать по порядку или заглядывать в нужный.

## ⚡ Самое нужное с первой минуты

| Действие | Как |
|---|---|
| Создать страницу | «Новая страница» внизу боковой панели |
| Вставить блок (заголовок, список, таблица, картинка) | Набрать `/` в пустой строке |
| Найти что угодно | `⌘K` / `Ctrl+K` - командная палитра |
| Сослаться на другую страницу | Набрать `[[` |
| Упомянуть человека или дату | Набрать `@` |
| Поделиться страницей | Кнопка «Поделиться» в верхней панели |
| Свернуть боковую панель | `⌘\` / `Ctrl+\` |

## 💡 Как karexo хранит ваши данные

- **Всё пишется само.** Кнопки «Сохранить» нет: правка сразу попадает в локальное хранилище
  браузера, а оттуда - на ваш сервер.
- **Работает без сети.** Правки, сделанные офлайн, копятся локально и догоняют сервер, когда
  связь вернётся. Одновременные изменения с разных устройств сливаются автоматически.
- **История не переписывается.** Документ - это журнал правок, поэтому доступны отмена
  (`⌘Z`), история версий и корзина.
- **Можно зашифровать.** Включите сквозное шифрование - и сервер будет хранить только
  шифртекст. Подробности и предупреждения: [🔒 Приватность и шифрование](privacy-encryption.md).

## 🆘 Если что-то не так

- **Страница не появилась на втором устройстве** - проверьте индикатор синхронизации в нижней
  строке приложения. «Офлайн» значит, что сервер сейчас недоступен, данные не потеряны.
- **Вместо текста пусто на новом устройстве** - вероятно, включено шифрование и сейф ещё не
  разблокирован. Введите парольную фразу.
- **Не хватает раздела в справке** - функции karexo развиваются; описанное здесь отражает
  текущую версию, а что изменилось - в [списке изменений](../CHANGELOG.md).
